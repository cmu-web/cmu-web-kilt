Get Started

The kit is two stylesheets and a script that go after CMU's template. Start from what you're building:

CMS site editors Add It to Your Site Add one line to your site's head code, in Cascade, Drupal or another CMS, then use the components on any page. Set Up a CMS Site App developers Build an App That Matches Install a release in a Node app, or copy its files into any other stack, then use the app components. Set Up an App Designers Try an Idea Link the kit straight from the CDN in a mockup or a one-off page, and see it in a browser right away. Start a Prototype
