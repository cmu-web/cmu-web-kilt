Find the Right Component

Page layouts, content blocks and app controls, with live examples and markup you can use in your own project.

Each one is labeled with what it needs:

  • Template is built into CMU's template, with nothing else to load.
  • CMS needs cmu-cms.css. It works on any page built on the template, in Cascade, another CMS or an app.
  • App needs cmu-app.css too, and cmu-app on <body>.
  • Script also needs cmu-app.js.
