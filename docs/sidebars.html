Sidebars

Boxes beside the content. Each div in a .sidebar is a box with no background until you give it one.

On This Page Template

Links to the sections of a long page: the template's list simple box, with no heading. Each link points to a section heading's id, and the template scrolls to it. Put it first in the sidebar, and leave it off pages short enough to see at a glance. For a page whose content uses the full width, use an On This Page link bank under the intro instead.

A Full Sidebar

A sidebar can hold several of these. Stack them in this order, leaving out what the page doesn't need:

  1. On This Page, on a long page
  2. A button box, for the page's one action
  3. Quick links
  4. Other boxes, with a dark box for questions last
